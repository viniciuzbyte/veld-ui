Less noise, more intention. A visual language built to give content its own space and interfaces a sense of permanence.

Design principles

Editorial hierarchy, generous whitespace, thin rules, and measured details create structure without visual clutter.

The system uses CSS custom properties and namespaced classes, so its foundations can be adapted to existing projects.

Start with one stylesheet

03 — No build step

Copy veld.css into your project and add the stylesheet to your document. Use the provided Veld classes, or build your own components from the CSS custom properties.

<link rel="stylesheet" href="./veld.css">

<div class="veld-shell">
  <p class="veld-label">Field note</p>
  <h1 class="veld-display">A quieter web.</h1>
  <a class="veld-link-arrow" href="#work">Explore work</a>
</div>
